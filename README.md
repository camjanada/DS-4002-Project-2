## Contents of This Repository

This repository contains the data, code, and outputs for classifying European paintings from The Metropolitan Museum of Art as 17th, 18th, or 19th century works [1]. The analysis uses pretrained ResNet-18 to extract visual features from the paintings and logistic regression to predict their century [2].

**Research question:** Can visual features of European paintings predict whether they were made in the 17th, 18th, or 19th century better than guessing the most common century?

**Performance goal:** Achieve test accuracy at least 10 percentage points higher than a baseline that predicts the most common century in the training set for every test painting.

The repository follows the course’s adaptation of TIER Protocol 4.0 [3].

- **`SCRIPTS/`** contains the data collection and model analysis notebooks.
- **`DATA/`** contains the dataset documentation and directions for obtaining the archived images and metadata.
- **`OUTPUT/`** contains figures generated by the analysis.
- **`REFERENCES/`** contains the project's references.
- **`LICENSE.md`** contains the MIT license for the project code.


**Current status:** The model exceeded the performance goal on both test splits. Accuracy was **60.0%** on the original painting-level split and **51.2%** when paintings with the same artist label were kept in the same split. Five-fold cross-validation was also used to compare different numbers of ResNet-18 features.

## Section 3: Instructions for Reproducing Results

### Step 1. Obtain the archived dataset

Follow the instructions in `DATA/README.md` to download `met_sample_balanced.zip`. Use the archived copy for the reported results. A new run against the live Met API may select different paintings.

If you want to repeat the collection process, open `SCRIPTS/metpulldata.ipynb` in Colab and run the collection cell. It queries the Met’s European Paintings department and saves public-domain paintings with readable images and date ranges that fall within one century. The notebook saves images to `met_sample/images/` and updates `met_sample/metadata_balanced.csv` as paintings are collected.

If collection stops before the target counts are reached, rerun the collection cell with the saved CSV and images still in the runtime. When the counts reach **67 paintings from the 17th century, 66 from the 18th century, and 67 from the 19th century**, run the export cell to download `met_sample_balanced.zip`.

### Step 2. Open the analysis notebook and upload the data

1. Download `SCRIPTS/ds_project_3.ipynb` and open it in [Google Colab](https://colab.research.google.com/).
2. Rename the downloaded dataset archive to **`paintings.zip`** and upload it using Colab’s **Files** panel.
3. Run the setup cell. It extracts the archive to `/content/paintings/` and reads `/content/paintings/metadata_balanced.csv`.
4. Check that the notebook reports **200 paintings**, the expected century counts, and **zero missing images**.

### Step 3. Run the painting-level analysis

1. Run the stratified 80/20 split with `random_state=42`. Check for **160 training paintings** and **40 test paintings**.
2. Run feature extraction. The notebook converts images to RGB, resizes them to 224 × 224 pixels, normalizes them, and extracts 512 ResNet-18 features per painting. The feature arrays should have shapes `(160, 512)` and `(40, 512)`.
3. Run the logistic regression, baseline, and confusion matrix cells. The model should correctly classify **24 of 40 paintings**. The baseline should predict the 19th century for all 40 test paintings and correctly classify **13 of 40**.

### Step 4. Run the artist-grouped analysis

1. Run the artist overlap check. The original split should have **14 artist labels** in both sets.
2. Run the grouped split. The notebook standardizes artist labels and selects the fold closest to holding out 20% of the paintings from each century. Check for **157 training paintings**, **43 test paintings**, and **zero shared artist labels**.
3. Run the cells that match the existing ResNet-18 features to the new split and fit a fresh logistic regression model. The model should correctly classify **22 of 43 paintings**. The baseline should correctly classify **13 of 43**.

### Step 5. Run cross-validation for feature selection

1. Run **artist-grouped cross-validation** on the 157 training paintings. The notebook compares **32, 64, 128, 256, and all 512 features** using five folds. Feature ranking and model fitting take place inside each training fold. The highest mean validation accuracy was **56.7% with 64 features**, compared with **48.6% with all 512 features**.
2. Run **ungrouped cross-validation** after the grouped search. This block reuses the same 157 paintings and feature counts with stratified folds that allow an artist’s works to appear across training and validation. The best feature count in this comparison was **128**.

### Step 6. Save the output and check the results

The notebook saves the original test confusion matrix to `/content/confusion_matrix.png`. Download it before closing the Colab session and place it in `OUTPUT/`. The diagonal of the matrix should sum to **24 correct predictions**.

| Test split | Test paintings | Model accuracy | Baseline accuracy | Improvement |
|---|---:|---:|---:|---:|
| Painting-level | 40 | 60.0% | 32.5% | +27.5 percentage points |
| Artist-grouped | 43 | 51.2% | 30.2% | +20.9 percentage points |

Improvements are calculated from unrounded accuracies. Both test results use all 512 features and exceed the 10-percentage-point goal. The 56.7% result for 64 features is the mean across the artist-grouped validation folds.

## Modeling Approach

### Feature extraction and classification

ResNet-18 uses pretrained ImageNet weights. Its final classification layer is replaced with an identity layer so that each image produces a 512-value feature vector. Logistic regression learns the relationship between those features and the three century labels using the training paintings.

### Baseline and evaluation

The baseline predicts the most common training century for every test painting. The model and baseline are evaluated on the same test paintings within each split. The artist-grouped split checks how well the model predicts centuries for paintings whose artist labels were absent from training.

### Feature selection

Within each cross-validation fold, `SelectKBest` ranks the ResNet-18 features using an ANOVA F-test on the training portion. Logistic regression is then fitted using the selected features. The feature count is chosen based on mean validation accuracy across five folds.

## Limitations

- The sample contains 200 paintings from a single museum collection, so performance may differ on works from other collections.
- The Met’s recorded date ranges may reflect estimates. Paintings whose ranges span multiple centuries were excluded.
- Artist groups are based on catalog labels. Alternate attributions or missing names can affect how paintings are grouped.
- The two test splits contain different paintings, so the change in accuracy cannot be attributed entirely to artist overlap.
